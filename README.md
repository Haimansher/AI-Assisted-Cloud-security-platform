# AI-Assisted Cloud Security Operations Platform

A low-cost, production-style cloud security portfolio project demonstrating AWS, Terraform, DevSecOps, SIEM, automation, and AI-assisted remediation.

## Goal

Secure a fictional AWS SaaS startup with limited budget while demonstrating:

- AWS cloud security fundamentals
- Infrastructure as Code with Terraform
- CI/CD security checks
- CloudTrail and CloudWatch logging
- Microsoft Sentinel trial integration
- n8n security automation
- FastAPI AI explanation service
- Streamlit executive dashboard

## Cost Strategy

This project is designed to stay low-cost by:

- Using one AWS region
- Avoiding NAT Gateway, ALB, RDS, paid VPC endpoints, and high-volume logs
- Running FastAPI and n8n locally
- Enabling Sentinel only during the trial/demo period
- Destroying AWS resources when not actively testing
